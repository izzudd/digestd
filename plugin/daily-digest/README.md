# Daily Digest

Pulls the daily RSS digest EPUBs built by feed.izzudd.my.id.

- Pick a date from the list to download it to /Digest on the SD card.
- A new digest is generated every day at 05:00 WIB.
- Old digests are removed after 7 days.

Dashboard (add or remove feeds): https://feed.izzudd.my.id
